# 参与共建

正文通过 Pull Request 审核，Issue 用于纠错、资料线索和选题建议。贡献不要求“写得像百科全书”，但必须区分事实、个人经验和推测。

## 最适合首批提交的内容

- 已修课程的结构化信息：学期、教师、考核构成、官方来源。
- 一次项目或竞赛复盘：目标、分工、技术栈、结果和可复用经验。
- 一篇学法文章：适用对象、方法、投入时间、失败条件。
- 师资或研究方向纠错：给出学院官网或教师本人主页链接。

## 提交流程

1. 先搜索[现有 Issue](https://github.com/YichengDong0219/njura-wiki/issues)，避免重复。
2. 小型纠错可直接发 Issue；正文或数据修改请 Fork 后提交 Pull Request。
3. 在 PR 中说明来源、最后核验日期、是否包含第三方版权内容。
4. 维护者检查事实、站内链接、版权边界与构建结果后合并。

## 三类内容的最低字段

### 课程

课程号、课程名、适用学期、授课教师、学分/考核、官方来源、资料链接、经验状态。

### 项目

项目类型、状态、参与条件、负责人或团队、时间、公开来源、核验日期。

### 学法文章

适用对象、先修基础、方法步骤、时间成本、可能失效的情况；个人观点需使用第一人称。

## 版权与隐私

- 不上传未获授权的课件、试卷、教材扫描件或网盘镜像。
- 不公开私人联系方式、群聊截图、成绩单和未经同意的人员信息。
- 教师简介以转述和来源链接为主，不复制照片、论文插图或长段原文。
- 代码采用 MIT；原创 Wiki 文本采用 CC BY-SA 4.0。课程文件的权利不因进入资料库而自动改变。

更完整的仓库协作规则见 [CONTRIBUTING.md](https://github.com/YichengDong0219/njura-wiki/blob/main/CONTRIBUTING.md)。
