# 课程投稿模板

复制下列模板到 Issue 或 Pull Request。事实字段需要官方教务、教学大纲或教师通知来源；个人经验单列，避免写成普遍结论。

```yaml
courseCode: 课程号
name: 课程名
term: 适用学期
instructors:
  - 教师姓名
credits: 学分；未知可写 null
assessment: 考核构成与来源
officialSource: URL
resourceLinks: []
experienceStatus: 暂无投稿 | 已有投稿
lastVerified: YYYY-MM-DD
```

## 学生经验建议结构

1. 你的先修基础与修读学期。
2. 每周大致投入，不夸大精确度。
3. 最有帮助的练习或资料，以及使用授权。
4. 这套方法对哪些同学可能无效。
5. 明确声明：个人经验不代表课程当期要求。
