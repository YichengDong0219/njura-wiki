# 项目介绍

项目栏目只收录有学院官网、论文、比赛结果或团队公开页面可核验的内容。参与条件没有公开时明确写“未公开”，不把历史参与经历包装成当前招募信息。

## 两个子栏目

- [学生实践项目](/projects/student/)：强调学生承担的真实模块、技术链路和公开成果。
- [学院科研项目](/projects/research/)：从学院公开成果页进入问题、方法、团队和论文。

## 首版原则

每条记录都包含状态、负责人或团队、时间、参与条件、来源和核验日期。项目评价与个人体验须由参与者投稿，并清楚标注主观性。

想补充项目？请按[贡献规范](/contribute/)提交来源，或使用下面的最小模板：

```yaml
title: 项目名称
kind: student_practice | research_project
status: 当前状态
participation: 参与条件；未公开则明确写未公开
lead: 负责人或团队
date: YYYY-MM-DD
source: 公开来源 URL
lastVerified: YYYY-MM-DD
```
