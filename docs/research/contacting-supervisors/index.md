# 联系导师：具体、克制、可回复

联系之前，先阅读导师学院主页、近期代表论文和实验室公开信息。邮件目标不是一次讲完自己，而是让对方能快速判断你的背景、兴趣和下一步交流价值。

## 建议结构

1. **一句身份**：年级、专业和与方向最相关的一项基础。
2. **具体兴趣**：点名一篇论文或一个公开项目，说明你理解的问题而非只写“非常感兴趣”。
3. **已有行动**：课程、复现、项目或一页阅读笔记；可以附公开仓库链接。
4. **现实投入**：每周可投入时间、可持续到何时，避免夸大。
5. **可回答问题**：询问是否适合进一步交流，或建议补哪些基础；不要要求即时承诺名额。

## 示例骨架

```text
主题：本科生科研交流｜姓名｜具体方向

老师您好，我是……
我阅读了您关于……的公开工作，理解其主要解决……，对……仍有一个问题。
我已完成……，相关代码/笔记在……；未来一学期每周可稳定投入……小时。
若方向合适，希望请教我应先补充哪项基础，或是否方便安排一次简短交流。
谢谢。
```

不群发同一封模板，不催促私人渠道，也不要附带包含身份证件、成绩单等敏感信息的公开链接。对方未回复不等于负面评价，可继续提升材料并寻找其他匹配方向。
