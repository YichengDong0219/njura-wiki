# 科研指南

科研入门不是先问“哪个方向最热门”，而是把兴趣、基础、可投入时间和真实问题对齐。本栏目把公开信息整理成一条可验证、可行动的路径。

## 四步起点

1. **浏览研究图谱**：先看六类编辑性方向，再进入相关人员档案核对官网表述。
2. **建立最小背景**：用一周补齐该方向的核心概念、常用工具和一篇高质量综述。
3. **复现小结果**：优先选择有代码、数据和清晰评测的论文，留下可阅读的复现记录。
4. **带着材料交流**：联系导师时说明已读内容、能投入的时间、具体问题与下一步设想。
