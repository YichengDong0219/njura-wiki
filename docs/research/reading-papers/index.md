# 论文阅读：从摘要到复现

## 第一遍：判断是否值得深读

用 15–20 分钟回答四个问题：研究要解决什么痛点？基线为什么不够？核心主张是什么？哪张表或哪个实验最直接支持主张？答不出时先不要陷入公式细节。

## 第二遍：拆开方法链路

画出输入、状态或观测、模型、目标函数、训练/求解过程和输出。对控制与机器人论文，还要记录仿真器、控制频率、传感器、硬件平台和安全约束。

## 第三遍：检查证据

- 基线是否公平，训练预算和信息输入是否相当？
- 消融实验是否真的隔离了关键模块？
- 指标是否对应作者宣称的能力？
- 仿真到真机、离线到在线之间有哪些未解释差距？

## 最小复现记录

```text
论文与版本：
环境 / 数据 / 硬件：
运行命令与提交哈希：
与论文设置的差异：
成功复现的指标：
失败现象与日志：
下一步最小实验：
```

复现不是“跑通 README”就结束。应保存版本、随机种子、环境差异和失败记录，让下一位同学能判断结果来自方法还是配置。
