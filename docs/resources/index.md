# 资料入口

课程详情页已经预留资料浏览、投稿和修改能力。当前还没有可公开浏览的资料，页面不会跳转到未准备好的外部仓库。

后续接入资料服务时，主站只读取课程资料的标题、类型、适用学期和更新时间；具体文件仍与 Wiki 正文分开管理。这样可以更换 GitHub 仓库、对象存储或审核接口，而不改动课程页面结构。

## 计划中的资料结构

```text
课程
└── 学年学期
    └── 授课教师
        ├── 课件
        ├── 笔记
        ├── 试卷
        └── 其他文档
```

每批资料都需要来源、权利人、授权说明、贡献者和适用学期。没有授权资料时，课程页保持明确的空状态。

## 后续入口

- **浏览**：从课程详情页查看该课程的资料索引。
- **投稿**：提交资料元数据、授权说明和文件。
- **修改**：对已有条目补充学期、类型或权利信息。

这些入口会在对应服务准备好后开放。现在可以先查看[贡献规范](/contribute/)，了解本站的审核与版权边界。

> [!WARNING]
> 课程文件不自动适用本站的 CC BY-SA 4.0 文本许可；每个资料条目以自己的权利说明为准。
