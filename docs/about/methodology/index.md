# 研究聚类方法与免责声明

最后核验：**2026-08-27**。

## 两层结构

学院简介公开列出四个上位研究域：机器人系统工程、复杂系统的精密控制与运维、智能无人系统、控制理论与应用。本站原样保留这四个官方入口。

为了帮助学生从具体技术进入人员档案，本站又将 25 个教师档案与 4 位专职科研人员的公开研究兴趣整理为六类等权导航：学习与具身智能、自主机器人、控制与安全、优化与预测、工业与能源、机电与装备。

六类导航是**学生 Wiki 编辑性整理**，不是学院公布的正式学科分类。

## 证据优先级

1. 学院人员详情页与学院简介。
2. 教师本人主页及其中明确列出的论文清单。
3. 论文 DOI 与 DBLP，用于验证公开成果主题。
4. Google Scholar 只保存由教师本人主页明确链接的档案 URL。

不会自动抓取引用量，不用同名搜索自动匹配身份，也不以论文数或引用量改变首页节点大小。

## 聚类规则

- 一人可以属于多个方向，交叉性不是重复数据。
- 只有官网或本人公开材料直接支持的主题才进入标签。
- 六个一级节点等权展示；“相关人员数”只说明当前记录覆盖，不表示投入规模或排名。
- 两位官网明确标注的兼职教师保留兼职标记；4 位专职科研人员单列身份。

## 限制

- 官网没有公开结构化 API，详情页日期不一定等于内容更新时间。
- DBLP 对控制、电气与工业论文覆盖不完整；Scholar 有限流、同名和时效问题。
- 研究兴趣、职称、招生与团队项目会变化，本站计划每学期人工复核一次。
- 本站不评价导师指导风格、招生概率、实验室氛围或研究“强弱”。
