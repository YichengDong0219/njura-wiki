# 工具链

## 最小开发环境

- Git：分支、提交、Pull Request 和问题追踪。
- Linux shell：文件、进程、权限、SSH 与日志。
- Python：数据、学习与快速实验；用虚拟环境锁定依赖。
- C/C++：算法效率、硬件接口与机器人系统。
- 编辑器或 IDE：格式化、静态检查、调试器和测试集成。

## 机器人与控制常见层次

1. **数值验证**：NumPy/SciPy 或同类工具。
2. **控制仿真**：从小型自写模型开始，再进入专业仿真器。
3. **机器人中间件**：理解节点、消息、坐标系、时间同步和回放。
4. **学习实验**：固定数据版本、随机种子、配置与指标。
5. **真机部署**：记录固件、控制频率、传感器标定和安全停机方式。

## 一份实验记录至少包含

```text
目标 / 假设
代码提交哈希
环境与依赖
数据或场景版本
关键配置
结果与失败日志
结论和下一步
```

工具名称会更新，习惯更重要：可复现、可比较、可回退、可交接。
