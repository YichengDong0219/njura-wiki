# 学法经验投稿模板

```markdown
# 标题

## 适用对象
年级、课程版本、先修基础。

## 我遇到的问题
具体情境，不泛化为所有同学。

## 做法
按时间或任务说明，附可公开来源。

## 时间成本
给区间，并说明估计方法。

## 结果与证据
作品、可复现实验、前后对比；不公开敏感信息。

## 何时可能无效
课程版本、基础差异、设备或时间限制。

## 最后核验
YYYY-MM-DD
```

请避免排名同学或教师、泄露未公开考题、承诺结果，以及把一次个人体验写成普遍事实。
