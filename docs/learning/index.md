# 学法分享

这个栏目把“我当时怎么学”写成可复用但不绝对化的经验。首版只提供结构和基础路线，等待真实修读者补充。

## 三条主线

- **数学与控制**：线性代数、概率统计、微分方程、优化、信号与系统、反馈控制。
- **软件与智能**：数据结构、Python/C++、Linux、机器学习、强化学习、仿真与实验管理。
- **硬件与系统**：电路、传感器、嵌入式、执行器、通信、机器人系统集成与安全。

三条线不必等长推进。选择一个可运行的小项目，让理论、软件和硬件在具体问题上相遇。
