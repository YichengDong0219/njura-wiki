# 培养与学习路径

## 第一阶段：建立可计算的基础

目标是把数学对象落实为代码和图：用 NumPy 验证矩阵分解，用简单系统理解稳定性与反馈，用数据结构练习复杂度和工程实现。

## 第二阶段：完成闭环

选择倒立摆、路径跟踪或小车导航等问题，完成建模、控制/规划、仿真、评测和失败分析。比起一次做大项目，更重要的是形成“假设—实现—证据—修正”的循环。

## 第三阶段：进入研究问题

从[研究图谱](/research/map/)选择一个二级标签，读综述和代表论文。不要同时追六个热点；先把一个基线复现到可比较，再判断自己喜欢理论推导、算法实验还是系统实现。

## 每学期留一份可迁移成果

- 一个有 README、环境锁定和测试的公开仓库；
- 一篇说明适用边界的课程或项目复盘；
- 一份能被同学继续使用的实验记录或工具脚本。

课程安排与培养要求始终以学院和教务当期文件为准。
